## About

**HuntGap** is a global free-deals platform, live at **[huntgap.com](https://huntgap.com)**.

Every 15 minutes it hunts public sources worldwide &#8212; airdrop platforms, AI credit
boards, game stores and local deal communities &#8212; then deduplicates every offer and
runs it through a rules-based **Trust Score**. Anything that asks for a seed phrase,
a private key, or an upfront payment never reaches the board.

- &#127760; Country-wise deal hunting &#8212; Germany, France, Spain, Japan, Singapore &amp; more
- &#129302; Free AI tokens, credits and API access, tracked daily
- &#128176; Crypto airdrops &amp; giveaways, scam-filtered by rules, not vibes
- &#9889; Deal of the Day, ranked Top 10, live expiry countdowns
